# Traffic Cat 桌面后台联网观察器需求文档（定稿）

## 1. 产品概述

本产品是一个面向桌面平台的后台联网观察器。

它由一个常驻桌面角落的“桌面守望挂件”和一个后台详细分析界面组成，用来持续记录本机网络流量的来源进程、目标地址、流量方向、活跃时间和流量规模。

产品目标不是抓包审计，也不是防火墙，而是提供一个低占用、可常驻、可回查、可提醒的个人桌面网络流向观察工具。

## 2. 产品定义

- 产品形态：跨平台桌面产品
- 首发平台：`Linux` 桌面，`X11` 优先
- 后续平台：`Windows`、`macOS`
- 首版形态：`agentd` 守护进程 + `desktop-ui` 桌面 UI
- 技术路线：`Rust + Tauri`
- 运行前提：允许 `sudo` 或系统能力
- 核心原则：
  - 低占用
  - 实时可见
  - 长期稳定运行
  - 能看清“谁在连哪里”
  - 能回查历史
  - 能给出轻量提醒

首版不做：

- Android
- 请求内容抓取
- 明文抓包审计
- 流量拦截或防火墙规则系统
- Wayland 完整兼容
- 复杂关系图谱
- 云同步

## 3. 前台挂件需求

前台挂件是一个始终在线的轻量桌面状态入口，不是完整监控面板。

### 3.1 默认展示

- 默认固定在屏幕右下角
- 支持拖动，记住最后一次位置
- 默认尺寸约 `220x84`
- 默认显示：
  - 守望角色主体
  - 当前上行速率
  - 当前下行速率
  - 一条最重要的实时摘要
- 实时摘要格式为：`进程名 -> 域名/IP`
- 空间不足时裁剪目标地址，不换行
- 空闲时半透明弱化显示
- 有活跃流量时恢复正常透明度

### 3.2 悬停展示

- 悬停后显示最近 `3` 条活跃流量
- 每条显示：
  - 进程名
  - 目标域名或 `IP`
  - 流量方向
  - 当前速率
- 不展示复杂图表，不展示历史统计

### 3.3 交互规则

- 单击：打开主界面，默认进入“实时流向”页
- 右键：打开简洁菜单
- 菜单项固定为：
  - 打开主界面
  - 暂停提醒 `30` 分钟
  - 显示或隐藏局域网流量
  - 退出 UI
- 双击：首版不定义行为
- 当前台检测到守护进程离线或权限不足时：
  - 守望挂件进入异常或困惑状态
  - 单击直接进入诊断页

## 4. 守望挂件状态机

守望挂件采用固定 `5` 态模型。

### 4.1 `idle`

- 条件：最近 `8` 秒无显著流量
- 表现：趴着、低频轻微动效

### 4.2 `download_active`

- 条件：下行流量明显高于上行，且超过活跃阈值
- 表现：朝向流入侧，关注输入方向

### 4.3 `upload_active`

- 条件：上行流量明显高于下行，且超过活跃阈值
- 表现：朝向流出侧，有主动动作

### 4.4 `bidirectional_active`

- 条件：上下行都处于活跃状态
- 表现：警觉但不告警

### 4.5 `alerting`

- 条件：任一告警规则触发
- 表现：耳朵立起，出现红点或提示气泡

### 4.6 状态切换规则

- UI 主状态每 `1` 秒刷新一次
- 单一状态最短驻留时间为 `2` 秒
- `alerting` 优先级最高
- 告警结束后返回当前实际流量状态
- 首版禁止高频闪烁和剧烈动画

## 5. 后台主界面需求

主界面首版固定包含四个功能区。

### 5.1 实时流向

展示当前活跃连接，至少包含：

- 进程名
- `PID`
- 父进程名
- 父 `PID`
- 目标域名或 `IP`
- 端口
- 协议
- 方向
- 当前速率
- 首次出现时间
- 最近活动时间
- 当前连接状态

### 5.2 按进程聚合

按进程展示：

- 累计上行
- 累计下行
- 最近活跃时间
- 连接目标数量
- 是否存在提醒标记

### 5.3 单进程详情

展示某进程的：

- 基础信息
- 最近连接目标
- 时间线式活动记录
- 流量统计摘要
- 相关告警记录

### 5.4 历史检索

支持以下过滤条件：

- 进程名
- 域名或 `IP`
- 端口
- 时间范围
- 入站或出站
- 是否显示局域网流量

首版不做复杂拓扑图谱，但允许做轻量时间线和排行展示。

## 6. 数据采集与归因

### 6.1 采集策略

- 首选 `eBPF`
- 需要系统能力或 `sudo`
- 若 `eBPF` 不可用，则回退到 `/proc` 与连接表相关方案
- 如果主采集与回退采集都不可用，则明确进入不可用状态，不伪造数据

### 6.2 记录粒度

每条流量记录或连接会话至少保留：

- 进程名
- `PID`
- 父进程名
- 父 `PID`
- 域名或 `IP`
- 端口
- 协议
- 方向
- 首次出现时间
- 最近活动时间
- 累计字节数
- 当前连接状态
- 采集模式

域名解析规则：

- 优先使用 DNS 或 TLS 主机名关联
- 无法解析时显示 `IP`
- UI 标出主机名来源

## 7. 告警需求

首版只做轻量提醒，不做拦截。

### 7.1 告警类型

#### 7.1.1 首次联网

- 定义：某进程最近 `30` 天内第一次外网连接
- 默认对系统基础进程降噪
- 同一进程只提醒一次

#### 7.1.2 流量突增

- 定义：最近 `1` 分钟平均流量相对前 `10` 分钟基线显著升高
- 无基线时不触发
- 小流量抖动不触发

#### 7.1.3 持续后台通信

- 定义：某进程持续外网通信超过 `10` 分钟
- 很小的心跳流量不触发

### 7.2 告警展示

- 前台挂件：红点或提示气泡
- 系统通知：默认开启
- 同一进程同类告警 `30` 分钟内只通知一次
- 主界面提供“最近提醒”列表
- 所有告警都可以跳转到对应进程详情页

## 8. 历史存储与导出

### 8.1 本地存储

- 使用 `SQLite`
- 默认保留 `30` 天历史
- 同时设置数据库软上限 `512MB`
- 超过时间或容量阈值时，优先删除最旧记录

### 8.2 默认展示范围

- 默认隐藏：
  - `localhost`
  - `127.0.0.1`
  - `::1`
  - 纯回环流量
- 局域网流量默认记录，但前台弱化展示
- 用户可在后台检索和切换显示

### 8.3 导出能力

首版支持导出：

- `CSV`
- `JSON`

导出范围支持：

- 当前筛选结果
- 指定时间区间

## 9. 运行状态与诊断

主界面必须提供明确状态信息：

- 守护进程在线或离线
- 当前采集模式
- 权限状态
- 数据精度是否降级
- 数据库状态

当进入降级模式时：

- 前台挂件显示轻量状态标识
- 主界面顶部显示当前模式和精度下降说明
- 用户能够区分“没有流量”和“采集能力下降”

## 10. 启动与安装要求

- `agentd` 由 `systemd` 管理
- `desktop-ui` 登录后自动启动
- 统一提供 `scripts/install.sh` 作为安装与卸载入口
- `scripts/install.sh` 支持：
  - `install`
  - `uninstall`
  - `uninstall --purge`
- 不带参数执行时，脚本进入交互式选择：
  - 安装
  - 卸载
  - 修复或重装
- 首次安装或重装时，脚本负责：
  - 安装守护进程
  - 注册服务
  - 检查 `eBPF` 与内核支持
  - 初始化数据库目录
- 已安装状态下再次执行安装时，默认按修复或重装流程处理
- 卸载时默认：
  - 停止并禁用服务
  - 删除程序文件和自启动项
  - 保留数据库和用户配置
- 执行 `uninstall --purge` 时，额外删除：
  - 数据库目录
  - UI 配置目录
  - 项目自身缓存目录
- 卸载后允许再次通过同一脚本重新安装
- 默认卸载后重新安装时，允许复用原有数据库与 UI 配置
- UI 不负责提权
- 权限问题统一由安装阶段和守护进程阶段处理

## 11. 核心接口要求

守护进程需至少提供以下接口能力：

- `GET /health`
- `GET /status`
- `GET /flows/live`
- `GET /flows/history`
- `GET /processes/:id/summary`
- `GET /processes/:id/flows`
- `GET /alerts`
- 实时事件流接口：`WS /events` 或本地 Unix Socket stream

实时事件至少包含：

- `timestamp`
- `process_name`
- `pid`
- `parent_process_name`
- `parent_pid`
- `direction`
- `remote_host`
- `remote_port`
- `protocol`
- `bytes_delta`
- `host_source`
- `capture_mode`
- `is_new_process`

## 12. 测试与验收标准

### 12.1 单元测试

- 流量聚合逻辑
- 历史过滤逻辑
- 告警判断逻辑
- 域名关联回退逻辑
- 数据淘汰策略

### 12.2 集成测试

- 多进程并发联网时能正确归因
- `eBPF` 不可用时能进入回退模式
- 历史查询和实时展示一致
- 首次联网进程可触发提醒
- 守护进程异常退出时 UI 能正确提示

### 12.3 手工验收

- 守望挂件可在 `X11` 桌面稳定常驻
- 常态下占用低、不卡顿
- 用户能快速看到“哪个进程正在连哪个地址”
- 用户能回查过去 `30` 天的连接记录
- 异常、权限不足、降级状态都有明确可见提示
- 执行 `scripts/install.sh uninstall` 后，服务和程序入口被移除，但默认数据仍保留
- 执行 `scripts/install.sh uninstall --purge` 后，数据和配置被彻底清理
- 卸载后再次执行 `scripts/install.sh install` 可以重新完成安装

## 13. 默认假设

- 当前版本首发 Linux 桌面，优先兼容 `X11`
- Windows 与 macOS 会沿用同一套挂件与主界面体验，后续补平台采集实现
- 首版聚焦个人桌面使用，不做企业级集中管理
- 首版以“观测”和“提醒”为核心，不承担拦截职责
- 前台只负责状态感知和入口，详细分析统一放到后台
